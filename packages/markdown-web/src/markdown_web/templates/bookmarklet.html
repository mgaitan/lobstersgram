Save the bookmarklets

Save these links as browser bookmarks to run them on the page you are reading.

  1. Drag either link below onto your browser's bookmarks bar.
  2. Open an article you want to save.
  3. Click the bookmark you saved. Markdown opens in a new tab; Telegraph publishes the page and opens it.
Save as Markdown Publish to Telegraph

These bookmarklets are permanent: they use the server's Telegraph account without an expiring session key. The bookmarklet sends the current page's HTML directly from your browser, so it can process pages the server cannot access itself, including JavaScript-rendered pages or pages available only to you.
