About

Turn web pages into Markdown, or publish them to Telegraph.

  • /md/<url> returns raw Markdown.
  • /t/<url> extracts and publishes a page to Telegraph.
  • /t/published/ lists the pages published on Telegraph by this service.
  • /t/jobs publishes a long Markdown brief in stages; poll its run_url until the job is complete.
  • Bookmarklets send the current page's HTML from your browser, so they can process pages the server cannot reach on its own.
  • Markdown front matter may include notify_telegram with comma-separated Telegram user or channel IDs; after publication, @MarkdownTelegraphBot sends only the Telegraph link to those recipients.

To receive a private notification, first open @MarkdownTelegraphBot and send /start. In a group, add the bot and allow it to send messages. In a channel, add it as an administrator with permission to post messages.

See also llms.txt for the machine-readable agent contract and the API documentation.

You can also use the command line:

uvx markdown-this <url> | uvx md-to-telegraph
